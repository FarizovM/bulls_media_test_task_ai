# Інструкції для frontend agents

- Пиши Vue 3 Composition API з TypeScript. Увесь видимий користувачу текст інтерфейсу — українською.
- Використовуй `src/services/api.ts` для запитів до бекенду та `src/services/auth.ts` для OIDC. Не читай і не зберігай access token в інших компонентах.
- Передавай `Idempotency-Key` для triage-запитів; при повторі тієї самої операції зберігай той самий ключ.
- Не клади OpenAI секрети у Vite `VITE_*` змінні: вони вбудовуються у frontend bundle. Публічні OIDC authority/client ID допустимі.
- Production Compose задає `VITE_REQUIRE_OIDC=true`; production збірка має вимагати валідні HTTPS OIDC параметри. Звичайна локальна `bun run build` лишається demo-збіркою без OIDC.
- Підтримуй вузькі екрани, збільшений текст на широких екранах, клавіатурну доступність і `prefers-reduced-motion`. Уникай анімацій, що зсувають вміст або швидко блимають.
- Не додавай `v-html` для звернень чи тексту моделі. Vue має безпечно екранувати текстові значення.
- Якщо змінюється API-контракт, синхронізуй типи з backend Zod-схемами.
